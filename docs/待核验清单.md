# 真实设备待核验清单（real_device_pending）

本文是**所有必须在真实 Windows + 奥维 + 用户数据/账号环境完成、当前尚未完成**的核验项全集。按 `DSH_实施任务书.md` 的 A–E 分组。

- 状态约定：`未完成`（默认）/ `部分完成`（已完成部分实机观测，但验收仍未完成）/ `已完成`（附真实设备证据链接或摘要）。2026-10-30 在真实 Windows 11 + 奥维 10.7.5 上完成了 A1–A3 与 A4–A6 的部分实测，**但没有一次成功的真实对象读写（账号非 VIP）**，B–E 组其余项仍未完成；证据汇总见 [win-test-report.md](win-test-report.md)。
- 证据要求：脱敏后的请求/响应片段、工具返回、日志（不含 PSK）、截图、数值记录（坐标/面积/耗时）、pytest 输出。证据放 `docs/` 下新文件或验收报告中，并在本表回填链接。
- 完成一项后同步更新：`docs/capabilities.md`（证据等级）、`docs/version-record.md`（环境版本）、`ovital_mcp/tools/capabilities.py` 的 `UNVERIFIED_ITEMS`（由 Lead/实现负责人改）。

> 本机已有的离线证据（**不能替代本清单**）：模拟奥维服务器协议闭环、官方样例回放、合成 DEM 的确定性集水区计算、GRASS 8.5.0 本机手工链、DSH patch 的 `--dump-config` 组合验证。它们只证明“离线可跑”，不证明真实联机与工程精度。
